エラーチェック概要
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
(1)AKTFエラーチェッカでは，check_list.txtに記載されている以下の項目に該
   当するエラーチェックを行う．

    ID |    カテゴリ名     |               チェック内容
   ----+-------------------+------------------------------------------
    T0 | environment check | configureの設定
    T1 | basic check       | テストシナリオの構成
    T2 | attribute check   | オブジェクトの属性
    T3 | object check      | オブジェクト内の依存関係
    T4 | condition check   | コンディション内の依存関係
    T5 | scenario check    | テストシナリオ内の依存関係
    T6 | property check    | プロパティ指定との関係
    T7 | multiple check    | テストシナリオ間の依存関係
    F  | filtering         | configureの設定とテストケースの関係

(2)T0とT2の項目は規則的にエラーファイル生成が可能のためツールでエラーフ
   ァイルを生成する．生成する項目は以下のように分けられる．

   ・T0: environment check
     - T0_001: configureの設定で記述されていない項目がある
     - T0_002: configureの設定値が指定された型と異なる
     - T0_003: configureの設定値が有効値でない
     - T0_004: configureがHashでない
     - T0_005: configureに規定されていない項目が記述されている
     - T0_006: 必要なマクロが定義されていない
     - T0_007: マクロの設定値が指定された型と異なる
     - T0_008: マクロの設定値が有効値でない
     - T0_009: マクロ定義部がHashでない
     - T0_010: ハードウェアカウンタ設定情報の設定値が指定された型と異なる
     - T0_011: ハードウェアカウンタ設定情報の設定値が有効値でない
     - T0_012: 各割込み番号のマクロとハードウェアカウンタ用の割込み番号が一致している
     - T0_013: support_enadis_interrupt_sourceがfalseであるが，ハードウェアカウンタに割付けるC2ISRの割込み属性がAK_DISABLEである
     - T0_014: use_multi_coreがfalseであるが，core_numが2以上である
     - T0_015: configureのバージョンとAKTGのバージョンが異なる

     [SC3，SC4限定]
     - T0_SC3_001: return_statusがEXTENDEDでない

   ・T2: attribute check
     - T2_001: パラメータの型が規定する型と異なる
     - T2_002: パラメータの値が有効値でない
     - (*)T2_003: 変数名が命名規則に反している

   ・T6: property check
     - T6_001: propertyにscが存在しない
     - T6_002: propertyにccが存在しない
     - T6_003: propertyにsiが存在しない
     - T6_004: propertyの設定値が指定する型と異なる
     - T6_005: propertyの設定値が有効値でない
     - T6_006: propertyに未定義のkeyが存在する

     [SC1-MC限定]
     - T6_SC1_MC_001: add_osap_error_hookがtrueだが，システム定義のエラーフックがない

   (*)の場合は，ツールを用いてエラーファイルを生成するには複雑な処理が
   必要ため，除外する．

(3)T1，T2_003，T3，T4，T5，T7，F項目のエラーファイルは作成されている．

----------------------------------------------------------------------
エラーファイル
----------------------------------------------------------------------
・エラーファイルは，AKTF実行時にエラーになるはずのTESRYデータおよび
  configure.yamlファイルを意味する．

・エラーファイル生成時にエラーファイルはツール実行ファイルのフォルダに
  生成される．さらに生成されたエラーファイルの全リストをファイルとして
  ツール実行ファイルのフォルダに保持する．そのファイル名は
  make_file_list.txtである．

・エラーファイルの生成は実行位置に関係なくどこでも生成可能である．

----------------------------------------------------------------------
シェルファイル
----------------------------------------------------------------------
・シェルファイルは，生成されたエラーファイルを簡単に実行できるようにす
  るためのシェルファイルである．

・シェルファイル生成時にシェルファイルは実行したフォルダに生成される．
  さらに生成されたシェルファイルの全リストをファイルとしてツール実行フ
  ァイルのフォルダに保持する．そのファイル名はmake_file_list.txtである．

・シェルファイルの生成は実行位置に関係なくどこでも生成可能である．

----------------------------------------------------------------------
ファイル削除
----------------------------------------------------------------------
・削除時はファイルを生成する際に共に生成されたmake_file_list.txt内のフ
  ァイルリストを参照して削除を行う．その理由は生成されたファイル以外の
  ユーザーのファイルが削除されることを避けるためである．
  したかって，削除時にmake_file_list.txtファイルが存在しない場合は削除
  が不可能になるが，その場合はmake_file_list.txtファイルを改めて生成す
  ることにより削除が可能になる．さらに削除するとmake_file_list.txtファ
  イルも削除される．

・ファイル削除は実行位置に関係なくどこでも削除可能である．

ツール使用方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
----------------------------------------------------------------------
プロファイルのオプション
----------------------------------------------------------------------

  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb

----------------------------------------------------------------------
ファイル生成のオプション
----------------------------------------------------------------------
・エラーファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -c

・シェルファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -s

----------------------------------------------------------------------
エラーファイルの生成
----------------------------------------------------------------------
・T0の全項目のエラーファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -c -t 0

・SC1で実施可能なT0の全項目のエラーファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -c -t 0 --sc 1
    * --sc オプションは1から4まで指定可能，何も指定しない場合は，SC1とする
    * --sc 1はSC1を意味する

・メモリ保護機能の機能レベル1で実施可能なT0の全項目エラーファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -c -t 0 -p 1
    * -p オプションは1から3まで指定可能，何も指定しない場合は，機能レベル2とする
    * -p 1はメモリ保護機能の機能レベル1を意味する

・マルチコアで実施可能なT0の全項目のエラーファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -c -t 0 -m

・T0項目内の細部項目のエラーファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -c -t 0 -l 1
    * -l オプションは1から13まで指定可能
    * -l 1 はT0_001を意味し，-l 6 はT0_006を意味する
    * T0_SC3_001の場合は，-l 31 を指定する(T0_SC3_001はSC3またはSC4の場合のみ実行可能)

・全項目のエラーファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -c -A

----------------------------------------------------------------------
シェルファイルの生成
----------------------------------------------------------------------
・シェルファイル生成はすべての項目で可能である．

・T1の全項目のシェルファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -s -t 1

・SC1で実施可能なT1の全項目のシェルファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -s -t 1 --sc 1

・メモリ保護機能の機能レベル1で実施可能なT1の全項目のシェルファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -s -t 1 -m 1

・T2項目内の細部項目のシェルファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -s -t 2 -l 1

・全項目のシェルファイル生成
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -s -A

----------------------------------------------------------------------
生成したファイルおよびフォルダの削除
----------------------------------------------------------------------
・削除は生成したすべてのファイルおよびフォルダを扱う．

・生成したファイルおよびフォルダの削除
  /trunk/aktsp/tools/aktg/aktf/test/err_check/error_checker.rb -r

エラーチェック方法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
・エラーチェッカは，エラーファイルからシェルファイルを作出し，作出した
  シェルファイルを実行することによりエラーチェックができる．以下はエラ
  ーチェックの順である．

  (1)T0またはT2のエラーチェックが必要な場合，T0またはT2のエラーファイル
     を生成する．T2_003はすでにエラーファイルが作成されている．

  (2)生成したT0とT2のエラーファイルからシェルファイルを生成する．または，
     作成されているT1，T2_003，T3，T4，T5，T6，T7のエラーファイルからシ
     ェルファイルを生成する．

  (3)生成されたシェルファイルを実行してエラーをチェックする．
