(2.2.1) システムサービステスト用フォルダの構成
----------------------------------------------------------------------
システムサービステストのファイル/フォルダ構成を以下にまとめる．

aktsp/
  └─syssrv_test/sc1/
       ├─alarm/            アラーム関連システムサービス格納フォルダ
       ├─counter/          カウンタ関連システムサービス格納フォルダ
       ├─event/            イベント関連システムサービス格納フォルダ
       ├─interrupt/        割込み関連システムサービス格納フォルダ
       ├─osctl/            OS関連システムサービス格納フォルダ
       ├─resource/         リソース関連システムサービス格納フォルダ
       ├─scheduletable/    スケジュールテーブル関連システムサービス格納フォルダ
       └─task/             タスクS関連システムサービス格納フォルダ

各関連システムサービス格納フォルダ(alarm，counter…)には，システムサー
ビス毎にフォルダがあり(フォルダ名はシステムサービス名と同じ)以下のファ
イルが格納される．

・PictMasterモデルファイル
・TCSファイル
・TESRYデータ(cmy形式)

例)
aktsp/
  └─syssrv_test/sc1/
       └─task/
            └─ActivateTask/
                 │  ActivateTask.xls           PictMasterモデルファイル
                 │  ActivateTask_normal.csv    正常系TCSファイル
                 │  ActivateTask_error.csv     異常系TCSファイル
                 ├─normal_tesry/
                 │     ActivateTask_normal.csv 正常系TESRYデータ(cmy形式)
                 └─error_tesry/
                        ActivateTask_error.csv  異常系TESRYデータ(cmy形式)

----------------------------------------------------------------------
(2.2.2) OS内部処理テスト(サービス保護機能)用フォルダの構成
----------------------------------------------------------------------

OS内部処理テスト(サービス保護機能)のファイル/フォルダ構成を以下にまとめる．

aktsp/
  └─error_test/sc1/
       ├─illegal_terminate_task/        タスク不正終了テスト用フォルダ
       │    └─notmerge_tesry/          マージ実行不可のTESRYデータを格納するフォルダ
       └─illegal_terminate_c2isr/       C2ISR不正終了テスト用フォルダ
              └─notmerge_tesry/         マージ実行不可のTESRYデータを格納するフォルダ

各テストの格納フォルダには，以下のファイルが格納される．

・PictMasterモデルファイル
・TCSファイル
・TESRYデータ(cmy形式)

例)
aktsp/
  └─error_test/sc1/
       └─illegal_terminate_task/                    タスク不正終了テスト用フォルダ
            │  illegal_terminate_task.xls            PictMasterモデルファイル
            │  illegal_terminate_task_NS1.csv        TCSファイル
            │    ：
            └─notmerge_tesry/                       マージ実行不可のTESRYデータを格納するフォルダ
                   illegal_terminate_task_NS1.cmy     TESRYデータ(cmy形式)
                     ：

----------------------------------------------------------------------
(2.2.3) OS内部処理テスト(保護違反時処理機能)用フォルダの構成
----------------------------------------------------------------------

OS内部処理テスト(保護違反時処理機能)のファイル/フォルダ構成を以下にまとめる．

aktsp/
  └─protection_test/sc1/
       ├─cpu_exception/            CPU例外テスト用フォルダ
       │    ├─merge_tesry/        マージ実行可能のTESRYデータを格納するフォルダ
       │    └─notmerge_tesry/     マージ実行不可のTESRYデータを格納するフォルダ
       │
       └─stack_monitoring/         スタックモニタリングテスト用フォルダ
             └─notmerge_tesry/     マージ実行不可のTESRYデータを格納するフォルダ

各テストの格納フォルダには，以下のファイルが格納される．

・PictMasterモデルファイル
・TCSファイル
・TESRYデータ(cmy形式)

例)
aktsp/
  └─protection_test/sc1/
       └─cpu_exception/                              CPU例外テスト用フォルダ
            │  cpu_exception.xls                      PictMasterモデルファイル
            │  cpu_exception_Merge.csv                TCSファイル
            │    ：
            ├─merge_tesry/                           マージ実行可能のTESRYデータを格納するフォルダ
            │     cpu_exception_Merge.cmy             TESRYデータ(cmy形式)
            │        
            └─notmerge_tesry/                        マージ実行不可のTESRYデータを格納するフォルダ
                   cpu_exception_NotMerge_NP_NS.cmy    TESRYデータ(cmy形式)
                     ：

(2.2.4) 追加テスト用フォルダの構成
----------------------------------------------------------------------

追加テストのファイル/フォルダ構成を以下にまとめる．

aktsp/
  └─additional_test/sc1/
       ├─syssrv_test            システムサービステストの追加テストを格納するフォルダ
       ├─error_test             OS内部処理テスト(サービス保護機能)の追加テストを格納するフォルダ
       ├─protection_test        OS内部処理テスト(保護違反時処理機能)の追加テストを格納するフォルダ
       ├─other_test             その他のテストを格納するフォルダ
       └─nontesry_test          スクラッチで開発したテストを格納するフォルダ
           │  sc1_nontesry.sh    スクラッチで開発したテストを実行するスクリプト(nondebug.MANIFESTで記載されたテストを実行する)
           │  nondebug.MANIFEST  デバッガを使用しないテスト一覧
           │  debug.MANIFEST     デバッガを使用するテスト一覧
           ├─syssrv_test        システムサービステストのスクラッチで開発したテストを格納するフォルダ
           └─other_test         その他のテストのスクラッチで開発したテストを格納するフォルダ

各テスト用フォルダ以下のファイルが格納される．
① AKTGで実行可能なテスト(nontesry_testフォルダ以外)
・TESRYデータ(cmy形式)
※ 以下のファイルは各テストによって存在する場合もある．
・PictMasterモデルファイル
・TCSファイル

例)
aktsp/
  └─additional_test/sc1/
      └other_test/
         └─hardware_counter/                                      ハードウェアカウンタテスト用フォルダ
             │  HardwareCounter.xls                                PictMasterモデルファイル
             │  HardwareCounter_N_001_4_1.csv                      TCSファイル
             │    :
             ├─merge_tesry/                                       マージ実行可能のTESRYデータを格納するフォルダ
             │    HardwareCounter_N_001_3.cmy                      TESRYデータ
             │    HardwareCounter_N_001_4_1.cmy                    TESRYデータ
             └─notmerge_tesry_configure/                          マージ実行不可のTESRYデータを格納するフォルダ(個別configure使用)
                  │  HardwareCounter_N_001_4_2.cmy                 TESRYデータ
                  │  HardwareCounter_N_001_4_3.cmy                 TESRYデータ
                  └─configure                                     個別configureファイルを格納するフォルダ
                        HardwareCounter_N_001_4_2_configure.yaml    aktg用confirueファイル
                        HardwareCounter_N_001_4_2_configure.yaml    aktg用confirueファイル



例)
aktsp/
  └─additional_test/sc1/
       │  debug.MANIFEST                        デバッガを使用しないテスト一覧
       │  nondebug.MANIFEST                     デバッガを使用するテスト一覧
       │  sc1_nontesry.sh                       デバッガを使用するテストの実行スクリプト
       └─syssrv_test/
             └─ActivateTask/                    ActivateTaskの追加テストを格納するフォルダ
                  │  ActivateTask.xls            PictMasterモデルファイル
                  │  ActivateTask_E_005.csv      TCSファイル
                  │    :
                  └─merge_tesry/
                        ActivateTask_E_005.cmy    TESRYデータ
                          :

② スクラッチで開発したテスト(nontesry_testフォルダ)
・out.c
・out.h
・out.arxml
・Makefile
・gdb_cmd-nios2(デバッガコマンドファイル)

例)
aktsp/
  └─additional_test/sc1/
       └─nontesry_test/
            └─syssrv_test/
                 └─ActivateTask/
                      └─ActivateTask_N_002_0005
                            out.c
                            out.h
                            out.arxml
                            Makefile

  - 実行手順
    ① aktsp/additional_test/sc1/nontesry_test/以下の階層をaktsp/obj_n
       ontesry/sc1フォルダにコピーする．

       
       例) aktsp/obj_nontesry/sc1/syssrv_test
